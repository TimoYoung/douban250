# Top250 Tracker

追踪豆瓣 / IMDb Top 250 排行榜的每一次变化。自动爬取、保存快照、对比差异，让你随时掌握榜单动态。

## 它能做什么

**探索电影** — 按评分、类型、地区、年份多维度筛选，支持排序和看过状态过滤，快速找到想看的电影。

**追踪榜单变化** — 每次榜单更新自动保存版本快照。哪些电影新上榜、哪些被挤出、排名升降多少，一目了然。

**版本对比** — 任意两个版本放在一起对比，自动识别新增、移除、排名变动。支持跨平台（豆瓣 vs IMDb）对比。

**标记看过** — 绑定豆瓣账号后自动同步你的"看过"列表，在榜单中标记已看过的电影，快速发现还没看的经典。

**多平台覆盖** — 同时追踪豆瓣和 IMDb 两个平台的 Top 250，自动关联同一部电影在不同平台的排名。

**排名历史** — 点击任意电影查看它的排名走势图，时间跨度覆盖所有历史版本，豆瓣和 IMDb 分别展示。

## 快速开始

### Docker 部署（推荐）

```bash
docker run -d \
  --name douban250 \
  -p 8000:8000 \
  -v ./data:/app/data \
  -v ./posters:/app/posters \
  --restart unless-stopped \
  timoyoung/douban250:latest
```

启动后访问 http://localhost:8000，用默认账号登录：

- 用户名：`admin`
- 密码：`admin123`

> 首次登录后请在控制台修改密码。

### 本地开发

```bash
# 后端
cd backend
uv sync
playwright install chromium
uv run uvicorn app.main:app --reload

# 前端（另一个终端）
cd frontend
npm install
npm run dev
```

## 使用指南

### 角色与权限

| 角色 | 能做什么 |
|------|---------|
| 游客 | 浏览榜单、搜索电影、查看版本对比 |
| 普通用户 | 以上 + 配置豆瓣账号、同步看过列表、修改密码 |
| 管理员 | 以上 + 爬取管理、版本管理、元数据补全、用户管理 |

### 探索页面

从各个维度发现电影：拖动滑块或直接输入评分和年份范围，点击类型和地区标签多选，支持按评分、年份、片名排序。筛选条件会同步到 URL，方便分享。

### 看过列表同步

在控制台 → 账户设置中填入你的豆瓣用户 ID（从你的豆瓣个人主页 URL 获取），点击"同步"即可。支持增量同步（只抓新标记）和全量同步（扫描全部并清理已删除）。Cookie 可选配置，不填也能同步。

### 定时任务

系统内置自动任务，管理员可在控制台配置：

| 任务 | 默认频率 | 说明 |
|------|---------|------|
| 豆瓣 Top 250 爬取 | 每周一上午 9 点 | 有变化时自动创建新版本 |
| IMDb Top 250 爬取 | 每天凌晨 4 点 | 关联豆瓣电影，未匹配的进入待确认队列 |
| 看过列表同步 | 未启用 | 自动同步所有用户的看过状态 |
| 元数据补全 | 每周日凌晨 5 点 | 补全缺失的电影详情（导演、简介、海报等） |

### 版本管理

管理员可在控制台查看所有历史版本、编辑日期、删除版本。删除时自动清理无关联的电影和海报文件。

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `DATABASE_URL` | 数据库连接 | `sqlite:///./data/douban250.db` |
| `SECRET_KEY` | JWT 密钥，生产环境务必修改 | `CHANGE-ME-IN-PRODUCTION` |
| `DEFAULT_ADMIN_PASSWORD` | 默认管理员密码（仅首次启动生效） | `admin123` |
| `DOUBAN_REQUEST_DELAY` | 爬虫请求间隔（秒），用于防反爬封禁。实际间隔会在此基础上加随机抖动，失败时自动指数退避 | `2.0` |

## 注意事项

- 豆瓣有反爬机制，系统会自动处理冷却和重试，无需手动干预
- Cookie 可选：配置后反爬保护更强，不配也能正常使用
- 如频繁遇到反爬封禁，可增大 `DOUBAN_REQUEST_DELAY`（如 `3.0` 或 `5.0`）；网络环境好时可适当减小
- IMDb 爬取依赖 Playwright，首次使用需执行 `playwright install chromium`
- 生产环境请修改 `SECRET_KEY` 和默认管理员密码
- 所有时间均为北京时间（UTC+8）
